## 📌 About This Repository

This repo is my personal DSA journey written entirely in **Go (Golang)**. Every concept is implemented from scratch with clean code, inline comments, and problem links. The syllabus follows a progressive path — starting from Go basics and ending at advanced graph algorithms and dynamic programming.

- 🗓️ **Daily practice** — one topic or problem per day
- 📂 **Organized by topic** — easy to navigate
- 💬 **Commented code** — beginner-friendly explanations
- 🔗 **Linked problems** — LeetCode / GFG references
